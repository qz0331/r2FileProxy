# R2 Presigned URL 技术文档

## 1. R2 兼容 S3 API

Cloudflare R2 完全兼容 AWS S3 API，使用相同的签名算法（AWS Signature Version 4）。

**R2 Endpoint 格式**：
```
https://<ACCOUNT_ID>.r2.cloudflarestorage.com
```

## 2. Presigned URL 工作原理

Presigned URL 是一种带有签名的临时访问 URL，允许用户在不需要暴露访问密钥的情况下，直接操作 R2 存储。

### 特点

- 默认使用 **HTTPS** 协议
- 包含签名、过期时间等参数
- 无需经过代理服务器，直接访问 R2
- 支持上传（PUT）和下载（GET）操作

### URL 结构示例

```
https://abc123.r2.cloudflarestorage.com/uploads/user1/test.txt
  ?X-Amz-Algorithm=AWS4-HMAC-SHA256
  &X-Amz-Credential=access-key-id/20240101/auto/s3/aws4_request
  &X-Amz-Date=20240101T120000Z
  &X-Amz-Expires=3600
  &X-Amz-SignedHeaders=host
  &X-Amz-Signature=xxxxxxxxxxxx
```

### 参数说明

| 参数 | 说明 |
|------|------|
| X-Amz-Algorithm | 签名算法，固定为 AWS4-HMAC-SHA256 |
| X-Amz-Credential | 凭证信息，包含 AccessKeyID 和日期 |
| X-Amz-Date | 签名时间（ISO 8601 格式） |
| X-Amz-Expires | URL 有效期（秒） |
| X-Amz-SignedHeaders | 参与签名的请求头 |
| X-Amz-Signature | 签名值 |

## 3. Go 实现代码

### 3.1 初始化 R2 客户端

```go
import (
    "context"
    "fmt"
    "time"

    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/config"
    "github.com/aws/aws-sdk-go-v2/credentials"
    "github.com/aws/aws-sdk-go-v2/service/s3"
)

// R2Client R2 客户端封装
type R2Client struct {
    client   *s3.Client
    bucket   string
    publicURL string
}

// NewR2Client 创建 R2 客户端
func NewR2Client(accountID, accessKeyID, secretAccessKey, bucket, publicURL string) (*R2Client, error) {
    cfg, err := config.LoadDefaultConfig(context.TODO(),
        config.WithRegion("auto"),
        config.WithCredentialsProvider(credentials.NewStaticCredentialsProvider(
            accessKeyID,
            secretAccessKey,
            "",
        )),
    )
    if err != nil {
        return nil, fmt.Errorf("加载配置失败: %w", err)
    }

    client := s3.NewFromConfig(cfg, func(o *s3.Options) {
        o.BaseEndpoint = aws.String(fmt.Sprintf(
            "https://%s.r2.cloudflarestorage.com",
            accountID,
        ))
    })

    return &R2Client{
        client:    client,
        bucket:    bucket,
        publicURL: publicURL,
    }, nil
}
```

### 3.2 生成上传签名 URL

```go
// GenerateUploadURL 生成上传签名 URL
func (r *R2Client) GenerateUploadURL(ctx context.Context, key string, expiresIn time.Duration) (string, error) {
    presignClient := s3.NewPresignClient(r.client)

    req, err := presignClient.PresignPutObject(ctx, &s3.PutObjectInput{
        Bucket: aws.String(r.bucket),
        Key:    aws.String(key),
    }, func(opts *s3.PresignOptions) {
        opts.Expires = expiresIn
    })
    if err != nil {
        return "", fmt.Errorf("生成上传签名失败: %w", err)
    }

    return req.URL, nil
}
```

### 3.3 生成下载签名 URL

```go
// GenerateDownloadURL 生成下载签名 URL
func (r *R2Client) GenerateDownloadURL(ctx context.Context, key string, expiresIn time.Duration) (string, error) {
    presignClient := s3.NewPresignClient(r.client)

    req, err := presignClient.PresignGetObject(ctx, &s3.GetObjectInput{
        Bucket: aws.String(r.bucket),
        Key:    aws.String(key),
    }, func(opts *s3.PresignOptions) {
        opts.Expires = expiresIn
    })
    if err != nil {
        return "", fmt.Errorf("生成下载签名失败: %w", err)
    }

    return req.URL, nil
}
```

### 3.4 删除文件

```go
// DeleteObject 删除 R2 对象
func (r *R2Client) DeleteObject(ctx context.Context, key string) error {
    _, err := r.client.DeleteObject(ctx, &s3.DeleteObjectInput{
        Bucket: aws.String(r.bucket),
        Key:    aws.String(key),
    })
    if err != nil {
        return fmt.Errorf("删除对象失败: %w", err)
    }
    return nil
}
```

### 3.5 获取文件信息

```go
// HeadObject 获取文件元数据
func (r *R2Client) HeadObject(ctx context.Context, key string) (*s3.HeadObjectOutput, error) {
    return r.client.HeadObject(ctx, &s3.HeadObjectInput{
        Bucket: aws.String(r.bucket),
        Key:    aws.String(key),
    })
}
```

## 4. 客户端使用示例

### 4.1 浏览器端上传

```javascript
async function uploadFile(uploadUrl, file) {
    const response = await fetch(uploadUrl, {
        method: 'PUT',
        body: file,
        headers: {
            'Content-Type': file.type || 'application/octet-stream',
        },
    });

    if (!response.ok) {
        throw new Error(`上传失败: ${response.status}`);
    }

    return response;
}
```

### 4.2 浏览器端下载

```javascript
// 方式一：直接跳转
function downloadFile(downloadUrl) {
    window.location.href = downloadUrl;
}

// 方式二：fetch 后处理
async function downloadAndSave(downloadUrl, filename) {
    const response = await fetch(downloadUrl);
    const blob = await response.blob();

    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = filename;
    a.click();

    URL.revokeObjectURL(url);
}
```

### 4.3 curl 测试

```bash
# 上传
curl -X PUT "<presigned_url>" \
  -H "Content-Type: text/plain" \
  -d "Hello, R2!"

# 下载
curl -X GET "<presigned_url>" -o output.txt
```

## 5. 安全注意事项

1. **过期时间**：建议设置为较短时间（如 1 小时），避免 URL 被滥用
2. **路径限制**：服务端生成 key 时应包含用户标识，防止越权访问
3. **文件大小**：可结合 Content-Length 限制上传文件大小
4. **HTTPS**：签名 URL 默认使用 HTTPS，确保传输安全
